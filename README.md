# Введение
В этом репозитории хранятся практические задания, выполненные мной в рамках предмета ***Comuter Vision*** в колледже. </br>
## Task 2 - Подсчет приседов на видео
Программа находит три точки ноги: бедро, колено и щиколтку. </br></br>
Далее, по координатам найденных точек, рассчитываются координаты и длины векторов, образующих угол. Затем по этим данным вычисляется косинус искомого угла, а после и сам угол (в радианах). </br></br>
Если угол пересекает воображаемую линию уровня глубины писеда (угол < 1.8 радиан), то переменная ***line*** принимает значение *True*. Когда человек поднимается и снова пересекает линию, ***line*** присваивается значение *False*, а счетчик приседов увеличивается на 1. </br>

## Task 3 - Введение кода на виртуальной клавиатуре
Программа определяет координаты кончика пальца и помечает ее синей точкой.</br>
Если синяя точка находится в рамках какой-либо клавиши клавиатуры, то она загорается.</br>
Если координата точки задерживается в рамках клавиши более чем на ***3 секунды***, то клавиша считается нажатой и цифра добавляется в переменную с кодом.
